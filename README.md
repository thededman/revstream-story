# RevStream: the story

A one-page site telling how RevStream, an in-house revenue system for a clinical
diagnostics lab, went from the billing lead's month-end spreadsheet to the system the
billing team runs on, built by one IT engineer working with Claude.

This repository holds only the page (`index.html`). It contains no code from the app, no
patient data, no case numbers and no company financial figures; names are left out on
purpose.

Published with GitHub Pages from the `main` branch.
